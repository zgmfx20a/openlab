# GitHub Pages へのデプロイ手順

このゲームは純粋な静的 HTML + JavaScript なので、GitHub Pages にそのまま公開できます。

---

## 1. GitHub でリポジトリ作成（ブラウザ）

1. https://github.com にログイン
2. 右上 **+** → **New repository**
3. **Repository name**: `aihack2025`（任意の名前でOK）
4. **Public** を選択（無料で公開できるのは Public のみ）
5. **Add a README / .gitignore / license** は **どれも作らない**（空のまま）
6. **Create repository** をクリック

---

## 2. このフォルダを git 管理して push（ターミナル）

```bash
cd ~/work/OpenLab/aihack2025_nibn4

# ① git管理を開始
git init

# ② 全ファイルをステージ（秘密情報が無いか確認してから）
git add -A

# ③ コミット
git commit -m "initial"

# ④ ブランチ名を main に
git branch -M main

# ⑤ GitHub のリポジトリを登録（<> の中を自分のID/リポジトリ名に）
git remote add origin https://github.com/<あなたのID>/aihack2025.git

# ⑥ アップロード
git push -u origin main
```

> **認証について**: push 時、HTTPS なら GitHub の **Personal Access Token** がパスワード代わりになります。
> 発行手順: GitHub → Settings → Developer settings → Personal access tokens → Generate new token → 権限 `repo` を付けて発行

---

## 3. GitHub Pages を有効化（ブラウザ）

1. push したリポジトリのページを開く
2. **Settings** タブ → 左メニュー **Pages**
3. **Source**: `Deploy from a branch` を選択
4. **Branch**: `main` / フォルダ `/(root)` を選択 → **Save**

---

## 4. 公開確認

- 数分待って以下を開く
- `https://<あなたのID>.github.io/aihack2025/`
- ゲームが表示されたら成功

---

## 5. （推奨）公開後の仕上げ

### QRコードのURLを公開先に設定

`medicine-delivery.html` 内の `VICTORY_SCREEN_CONFIG.qrUrl` を変更：

```js
qrUrl: 'https://<あなたのID>.github.io/aihack2025/?result=victory'
```

### 更新方法

```bash
git add -A && git commit -m "更新内容" && git push
```

### 不要ファイルの削除（任意）

`_unused/` は古い動画・画像などで、公開する必要がありません。消しておくと安全・軽量です。

```bash
git rm -r _unused && git commit -m "remove unused" && git push
```

### 注意点

- `.nojekyll` と `index.html`（リダイレクト）は既に用意済みなのでそのままでOK
- `gvrm/`（各約40MB）は初回ロードが重いため、デモでは「ピノキオ」（軽量・コード生成）を選ぶと快適
- ウェブカメラ機能は GitHub Pages（HTTPS）上で動作する

## トラブルシューティング

| 症状 | 対処 |
|------|------|
| `Address already in use` | ポートが使用中。`python3 server.py 8080` など別ポートで |
| 画像・音が404 | 日本語フォルダ名はエンコードの問題になりがち。`backsound/` にリネーム済み |
| push が認証エラー | Personal Access Token を発行して使う |
| ページが反映されない | 数分待つか、ブラウザのキャッシュを消す（Shift+F5） |
