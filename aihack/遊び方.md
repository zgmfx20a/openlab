# ASI DIVE — 薬物配送ミッション 遊び方

## 概要

体内を探索し、**薬を拾って病巣に投下する**ステルスアクションゲームです。
免疫細胞（マクロファージ・白血球）に見つからないように進みます。

## 起動方法

```bash
python3 server.py
```

ブラウザで `http://localhost:8000/medicine-delivery.html` を開きます。

## ゲームの流れ

```
アバター選択 → 薬を拾う → 免疫細胞を避ける → 病巣に薬を投下 → クリア
```

### 1. アバター選択
- **サンプル5 / サンプル4**: 既存アバターから選択（実在人物のスキャン画像です）
- **ピノキオ**: 木の人形風アバター（コードで生成、実在人物なし）
- **新規作成**: Web カメラで顔を撮影すると、撮影した**顔写真＋システムが自動生成するボディ**でアバターを作成します（写真1枚から本物のガウシアンVRMを生成する処理はデモでは省略しています）

### 1-2. 難易度選択

アバター選択画面の下に難易度があります（デフォルトは「やさしい」）。

| 難易度 | マクロファージ | 白血球 |
|--------|--------------|--------|
| やさしい | 1体 | 1体 |
| ふつう | 2体 | 3体 |
| むずかしい | 3体 | 4体 |

設定はスクリプト内の `LEVEL_CONFIG`（敵の数・配置・速度）で変更できます。

### 2. ミッション
| 目標 | 内容 |
|------|------|
| ① 薬を拾う | スタート地点付近の緑の光るカプセルに近づく |
| ② 病巣に薬を投下 | マップ奥の赤く光る病巣まで薬を運ぶ |

### 3. 操作

| キー | 操作 |
|------|------|
| W / ↑ | 前進 |
| A / ← | 左移動 |
| S / ↓ | 後退 |
| D / → | 右移動 |
| Shift | ダッシュ |
| Esc | ポーズ |

ゲームパッド（PS5 / Xbox）も使用できます。

### 3-2. 体内の見どころ

赤い皿形の浮遊物は赤血球で、天井付近と床付近を漂っています（プレイヤーの視界は妨げません）。
薬を運んでいる間、画面中央上に病巣の方向を示す赤い矢印が表示されます。

### 4. 敵（免疫細胞）

| 種類 | 見た目 | 特性 |
|------|--------|------|
| マクロファージ | 緑色・大型（アメーバ状） | 動きが遅い、検知範囲が広い |
| 白血球 | 青白・小型（分葉核あり） | 動きが速い、複数配置 |
| 好中球 | 淡い紫色・小型（分葉核＋顆粒） | 最も速く、群れて襲う |
| マスト細胞 | 赤色・大型（静止・顆粒だらけ） | 動かない。薬を持ったまま近づくと**爆発**して即死（近づくと脈動が速くなって警告） |

- 敵の頭上には種類のラベルが表示されます
- 薬を**持っていない**間は敵に触れても安全です
- 薬を**持った状態**で敵に近づくと敵は**警戒して追跡**します（敵が赤く光る）
- 薬を**持った状態**で敵に触れると **即死・ゲームリセット**
- 敵に追跡されている間は画面が赤く警告表示され、警告音が鳴ります

### 5. クリア条件
病巣（マップ奥の赤い光柱・床の標的リングがある場所）に近づくと薬が自動投下され、**ミッション成功**です。
病巣には「⚠ 病巣」のラベルと上空への赤い光柱が立っているので遠くからでも分かります。

## UI 表示

| 要素 | 説明 |
|------|------|
| ミニマップ (右下) | プレイヤー(白)・敵(紫/赤)・薬(緑)・病巣(赤) の位置 |
| 進行度バー (下部) | 病巣までの距離を示す |
| ミッションパネル (右上) | 現在の目標を表示 |
| 薬インジケーター | 薬を所持中は 💊 アイコンが表示 |
| 危険警告 | 薬所持中に敵に追跡されると画面が赤く点灯 |

## デモプレイモード

無操作が約20秒続くと、**AIが自動で薬を拾って病巣に投下するデモプレイ**が始まります（ピノキオが操作します）。
クリア後は数秒待って自動で再開します。キーボード・マウスを操作すると通常の手動プレイに戻ります。
設定はスクリプト内の `DEMO_CONFIG`（無操作時間・自動アバター・クリア後の待機秒数）で変更できます。

## 備考

- 障害物（組織片）にはぶつかると移動できません
- 背景BGMが再生されます（音量 40%）
